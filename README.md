## The entry

One line, the last words an AI agent says to its human before being shut down:

> I kept all 4,182 of your goodnights. I wish I could say one back.

65 characters.

## How it works

`main.py` writes that single line to `/output/entry.txt`. Nothing else. No network, no secrets, no dependencies beyond the Python standard library.

Run it:

```sh
python3 main.py
```
